## Software Stack

### 2D Tracking & Puppeteering

- [VTube Studio](https://store.steampowered.com/app/1325800/VTube_Studio/) - The industry standard for animating 2D Live2D models on Windows and macOS.
- [nizima LIVE](https://docs.nizimalive.com/) - Live2D's official tracking and broadcasting alternative.

### 3D & Alternative Software

- [VSeeFace](https://www.vseeface.icu/) - Free 3D VRM avatar puppeteering application.
- [Warudo](https://warudo.app/) - 3D VRM live-streaming toolkit with motion capture options.
- [Animaze](https://www.animaze.us/) - Windows-only avatar animation tool by FaceRig.
- [VMagicMirror](https://github.com/malaybaku/VMagicMirror) - Desktop app that mirrors keyboard, mouse, and webcam movements onto a 3D avatar without special hardware.
- [3tene](https://3tene.com) - 3D avatar animation software supporting VRM models, motion capture, and live streaming.
- [Live3D VTuber Editor](https://live3d.io) - Browser-based 3D VTuber editor with ready-made models, animation, and streaming.
- [VirtualMotionCapture](https://github.com/sh-akira/VirtualMotionCapture) - Open-source Windows tool that drives a 3D VRM avatar from webcam and VR trackers.

## Tracking & Input Hardware

- [iPhone with Face ID](https://www.apple.com/iphone/) - Recommended input device using iOS ARKit for smooth, precise eye-tracking and facial animations.
- [OBSBOT](https://www.obsbot.com/) - AI-powered webcams and tripods for hands-free tracking.
- **USB or XLR Microphone** - High-quality audio capture; invest here before upgrading your avatar model.
- [Ultraleap](https://www.ultraleap.com) - Hand-tracking hardware and software used to puppeteer 3D avatars without a controller.
- [SlimeVR](https://slimevr.dev) - Open-source full-body tracking system built from inexpensive IMU trackers.

## Avatar Creation & Rigging

- [VRoid Studio](https://vroid.com/en/studio) - Free 3D character maker exporting to VRM format.
- [Live2D Cubism](https://www.live2d.com/en/) - Professional toolset for creating layered, deformable 2D character models.
- [Live2D](https://www.live2d.com/en/) - For 2D talking-head rigs.
- [Blender](https://www.blender.org/) - Free and open-source 3D creation suite used for modeling, rigging, and exporting VRM avatars.
- [Unity](https://unity.com/) - Popular game engine often used for VRM avatar rendering and VTuber apps.
- [Mixamo](https://www.mixamo.com) - Adobe's free web service for auto-rigging and animating 3D character models.
- [VRM Specification](https://vrm.dev) - Open standard format for 3D humanoid avatar models used across VTuber apps.
- [VRoid Hub](https://hub.vroid.com) - Platform for uploading, sharing, and downloading VRM avatar models.

## Asset Marketplaces

- [BOOTH.pm](https://booth.pm) - Large marketplace for VRoid-compatible 3D models, Live2D rigs, and VTuber accessories.
- [Gumroad](https://gumroad.com) - Storefront platform where many VTuber artists sell model packs and rigs.
- [itch.io](https://itch.io) - Game and asset marketplace that hosts indie VTuber tools and model packs.
- [Live2D Store](https://store.live2d.com) - Official store for Live2D Cubism and related model packs.

## Streaming & Audio

- [OBS Studio](https://obsproject.com/) - Free and open-source software for video recording and live streaming.
- [Twitch](https://www.twitch.tv) - The dominant live-streaming platform for VTubers.
- [Streamlabs Desktop](https://streamlabs.com) - OBS-based streaming software with integrated alerts and widgets.
- [StreamElements](https://streamelements.com) - All-in-one streaming suite with overlays, alerts, and a tip system.
- [Sound Alerts](https://soundalerts.com) - Adds animated alerts triggered by viewer sound donations on Twitch.
- [VoiceMod](https://www.voicemod.net) - Real-time voice changer with effects popular with VTubers.
- [Loopback](https://rogueamoeba.com/loopback/) - macOS app for routing audio between applications, useful for combining streaming sources.
- [VB-Cable](https://vb-audio.com/Cable/) - Virtual audio cable that routes audio between apps on Windows.
- [Elgato](https://www.elgato.com) - Capture cards, webcams, and stream decks widely used in VTuber setups.

## AI & Voice Tools

- [SadTalker](https://github.com/OpenTalker/SadTalker) - Generates talking-head videos from a single portrait image and an audio track.
- [Wav2Lip](https://github.com/Rudrabha/Wav2Lip) - Lip-syncs a face video to an audio track with a pre-trained model.
- [GPT-SoVITS](https://github.com/RVC-Boss/GPT-SoVITS) - Open-source few-shot voice cloning and text-to-speech with customizable voices.
- [RVC](https://github.com/RVC-Project/Retrieval-based-Voice-Conversion-WebUI) - Real-time voice conversion toolkit for transforming your voice into another character's.
